Panduan Pemisahan File Pembeli & Admin

Aplikasi ini dapat digunakan secara langsung dalam **1 file `index.html`** ini dengan berpindah via tombol header.

Jika Anda ingin memisahkannya menjadi 2 file HTML independen (`pembeli.html` dan `admin.html`):

  1. Salin seluruh kode file `index.html` ini ke `pembeli.html` dan `admin.html`.
  2. Pada `pembeli.html`, setel panggilan awal di script menjadi `switchPortal('buyer')`.
  3. Pada `admin.html`, setel panggilan awal menjadi `switchPortal('admin')`.
  4. Kedua file akan **otomatis tersinkronisasi secara realtime** melalui `localStorage` dan `BroadcastChannel` browser!
